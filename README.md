<h1>프론트엔드 실무 완성 커리큘럼</h1>

<p>Tailwind CSS, Shadcn UI, Zustand, TanStack Query, Supabase를 활용하여 효율적이고 확장 가능한 프론트엔드 개발 능력을 배양합니다.</p>

<hr>

<h2>기본기 및 아키텍처 설계</h2>

<h3>섹션 1: 프로젝트 준비</h3>
<ul>
  <li>환경 설정 및 리액트 앱 초기화</li>
</ul>

<h3>섹션 2: 스타일링과 라우팅</h3>
<ul>
  <li>Tailwind CSS 및 Shadcn UI 설정</li>
  <li>React Router V7을 활용한 라우팅 설계</li>
</ul>

<h3>섹션 3: 전역 상태 관리</h3>
<ul>
  <li>Zustand를 이용한 효율적인 클라이언트 상태 관리</li>
  <li>실전 투두리스트(Todo-list) 구현</li>
</ul>

<h3>섹션 4: 서버 상태 관리</h3>
<ul>
  <li>TanStack Query를 활용한 강력한 데이터 페칭</li>
  <li>서버 데이터 캐싱 메커니즘 이해 및 적용</li>
</ul>

<hr>

<h2>메인 프로젝트 (섹션 5~11): 한입 로그 SNS 구현</h2>
<p>배운 기술 스택을 총망라하여 실무 수준의 SNS 어플리케이션을 개발합니다.</p>

<ul>
  <li><strong>인증 (Auth):</strong> Supabase 기반 회원가입/로그인, 소셜 로그인 연동, 안전한 라우트 가드 구현</li>
  <li><strong>포스트 (Post):</strong> 게시글 CRUD, 이미지 업로드, 무한 스크롤(Infinite Scroll), 캐시 최적화</li>
  <li><strong>상호작용 (Interaction):</strong> 사용자 경험을 극대화하는 좋아요(낙관적 업데이트), 대댓글 및 무한 중첩 댓글 기능</li>
  <li><strong>프로필 및 테마 (UI/UX):</strong> 상세 프로필 관리 기능, 다크 모드 및 라이트 모드 전환 구현</li>
</ul>

<hr>

<h2>섹션 12: 배포 및 마무리</h2>
<ul>
  <li>완성된 프로젝트의 실서버 배포 (Deployment)</li>
  <li>전체 개발 과정 회고 및 최종 정리</li>
</ul>
